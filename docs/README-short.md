# PulseListen AI — Short Description

**PulseListen AI** is a privacy-first, multilingual social listening platform for real-time pharmacovigilance and outbreak detection. It ingests social media posts from X/Twitter, Reddit, and forums, redacts all Protected Health Information at the ingestion edge (DPDP Act 2023 compliant), and runs zero-shot classification to detect novel adverse drug reactions that aren't in any existing MedDRA dictionary. The platform processes 7 Indian languages natively (Hindi, Kannada, Tamil, Telugu, Bengali, Marathi, English), analyzes signal propagation through a Temporal Graph Diffusion Engine to distinguish genuine outbreaks from bot-amplified misinformation, maps geographic spread across Indian states with interactive heatmaps, and auto-generates regulatory-grade ICSR reports directly submittable to CDSCO and WHO VigiBase. Built with Next.js 16, Prisma, and a premium dark glassmorphism UI.
